# Writing

This page is a shared CryptPad — anyone with the link can edit it together, live. We're using it to practice **Markdown**, the plain-text formatting language that powers this whole site.

A quick cheat sheet:

- `# Heading` → big heading (use `##` for smaller, `###` smaller still)
- `**bold**` → **bold**, `*italic*` → *italic*
- `- item` on its own line → a bullet list
- `[link text](https://example.com)` → a [link](https://example.com)
- Blank line between paragraphs

Try it in the pad below — the left side is what you type, the right side is what it looks like.
